# Инструкции проекта

Перед изменениями изучай фактический код, актуальную документацию и локальные
`AGENTS.md`. Для любых задач backend обязательно прочитай `backend/AGENTS.md`:
там закреплены ограничения пользователя и принятая структура Python-приложения.

Без прямой просьбы пользователя не запускай тесты, сборки, серверы, контейнеры,
миграции, установку зависимостей и проверки, исполняющие приложение. Проверяй
изменения чтением исходников и сопоставлением контрактов. Анализ задачи сам по себе
не разрешает её реализацию. Сохраняй чужие изменения и состояние индекса Git.
